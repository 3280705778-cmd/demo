### 常用 Git 命令表格

| 命令 | 作用 | 什么时候用 |
|------|------|------------|
| git init | 初始化一个本地仓库 | 开始一个新项目时 |
| git add . | 将所有更改添加到暂存区 | 准备提交前 |
| git commit -m "说明" | 提交暂存区的更改 | 保存一次版本记录时 |
| git branch 分支名 | 创建新分支 | 开发新功能时 |
| git merge 分支名 | 合并指定分支到当前分支 | 功能完成，合并到主分支时 |
| git push origin main | 推送本地提交到远程仓库 | 需要同步到 GitHub 时 |
